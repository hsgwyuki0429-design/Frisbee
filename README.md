# DISC ISLAND（ディスクアイランド）

カラフルな島々をめぐる 3D ディスクゴルフ（フリスビー）ゲームです。
ブラウザだけで動き、スマホ（タッチ）と PC（マウス）の両方で遊べます。

## あそびかた

ディスクのうしろからの視点で、2 つの操作だけで投げます。

| 操作 | スマホ | PC | 決まるもの |
| --- | --- | --- | --- |
| ディスクを回す | 2本指ドラッグ（上下＝角度、左右・ひねり＝傾き） | 右ドラッグ / Shift＋ドラッグ / 矢印キー | 投げ出す角度・ディスクの傾き（傾きは360°） |
| 投げる | 1本指でディスクをなぞってスワイプ | 左ドラッグでスワイプ | 方向・パワー・回転 |

スワイプは次のように解釈されます。

- **方向**：スワイプと平行で、ディスクの中心を通る向きに飛び出します。
- **パワー**：スワイプの速さ（指を止めてから離すと弱くなります）。
- **回転**：スワイプの線がディスクの中心からどれだけ離れているか。中心を通すと回転ゼロでフラフラ落ち、端に近いほど回転数が上がります。中心の右側をなぞると左回り（上から見て反時計回り）、左側だと右回りです。縁から外れすぎると「かすった」扱いでパワーが落ち、ディスクに触れていなければ投げられません。

ディスクはドッジビーのような柔らかいフチの軽いディスク（20 / 23.5 / 27cm）で、ふわっと滑空します。
回転の向きと量で、終盤に曲がる方向（フェード）や安定性が変わります。

### モード

- **コース**：3 ワールド × 3 ホール（はらっぱ・ビーチ・空の島）＋ 全 9 ホールのチャンピオンシップ。前のワールドをクリアすると次が開放されます。
- **チャレンジ**：ロングドライブ（飛距離）／まとあて（5 投）／リングくぐり（3 投で 10 個の輪）。メダルでボーナスコイン。
- **れんしゅう**：距離の違う 4 つのバスケットと飛行データ表示つきの練習場。
- **きせかえ**：集めたコインでディスクのデザインを購入。
- **せってい**：BGM・効果音・スワイプ感度・画質・スロー演出・前回の軌道・振動。

記録・コイン・設定はブラウザの localStorage に保存されます。

## 技術メモ

- 描画：[three.js](https://threejs.org/)（トゥーンシェーディング、アウトライン、インスタンシング）。テクスチャ・モデル・効果音・BGM はすべてコードで生成しており、外部アセットはありません（フォントのみ Google Fonts）。
- 物理：自作の 3D 剛体物理エンジン（`src/physics/`）。
  - ディスクの状態（位置・速度・姿勢クォータニオン・ワールド角運動量）を RK4 で積分します。角運動量を積分するのでジャイロ効果が正確に出て、ピッチングモーメントが「ターン」「フェード」として現れます。
  - 揚力・抗力・ピッチングモーメントは迎え角の関数（失速後は平板モデルにブレンド）。風は相対気流として扱います。
  - 地形ハイトフィールド・箱・円柱・球・楕円体・トーラスとの衝突を、サンプル点とサポート点で検出し、逐次インパルス法（反発・摩擦）で解きます。木の葉やバスケットのチェーンは減速ボリュームです。
- 調整用のヘッドレス飛行シミュレータ：`scripts/simflight.ts`

## 開発

```bash
npm install
npm run dev        # 開発サーバー
npm test           # 物理エンジンのユニットテスト
npm run build      # 型チェック + 本番ビルド（dist/）
npm run preview    # ビルド結果の確認
```

Node.js 20 以上（推奨 22）。

## Cloudflare Pages で公開する

静的サイトとして `dist/` をそのまま配信できます。

### ダッシュボードから（Git 連携）

1. Cloudflare ダッシュボード → **Workers & Pages** → **Create** → **Pages** → **Connect to Git** でこのリポジトリを選択
2. ビルド設定
   - Framework preset: `None`（または `Vite`）
   - Build command: `npm run build`
   - Build output directory: `dist`
   - 環境変数（任意）: `NODE_VERSION` = `22`（`.node-version` でも指定済み）
3. **Save and Deploy**。以後 `main` への push で自動デプロイされます。

### CLI（Wrangler）から

```bash
npm run build
npx wrangler pages deploy        # wrangler.toml の pages_build_output_dir（./dist）を使用
```

初回は `npx wrangler login` が必要です。

`public/_headers` でハッシュ付きアセットに長期キャッシュを設定しています。
アセットは相対パス（`base: './'`）で出力されるため、サブパスでの配信にも対応します。
